# 🦀 Todo CLI (Rust)

A simple, fast, and persistent command-line todo application built in Rust.

This project demonstrates real-world Rust concepts including CLI design, file persistence, serialization, and modular architecture.

---

# 🚀 Features

- ➕ Add tasks
- 📋 List all tasks
- ✔ Mark tasks as done
- ❌ Delete tasks
- 💾 Persistent storage using JSON file
- ⚡ Fast native CLI binary

---

# 🧠 Tech Stack

- Rust
- Serde (JSON serialization/deserialization)
- Clap (CLI parsing - optional/upgradeable)
- std::fs (file system storage)
